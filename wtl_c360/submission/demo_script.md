# Demo script

1. Start with the full-data row-count reconciliation and show that the 31 source tables match the release schema while the manifest records file-size checks separately.
2. Show the bronze-to-curated flow, the deterministic CRM anchor, the match-candidate queue, and the isolated ambiguous identities awaiting steward review.
3. Demonstrate that Layer 2 is a separate DuckDB database with a curated column allowlist, masked notes/transcripts, current policy chunks, a minimum group size for team leads, and agent portfolio scoping.
4. Ask a guarded data question and a policy question. Show the structured result or refusal, source citation, and audit event.
5. Compare a batch feature row with the live single-customer result, then show multi-date training labels and an example note/transcript evidence ID behind a text flag.
6. Present the temporal holdout metrics beside the logistic baseline, calibration bins, group fairness audit, and the explicit selection-bias caveat.
7. Show that hardship, disputed/held cases, missing consent, or the rolling call cap route to a human or suppress further contact. Record a supervisor override with rationale and show the audit log.

Do not present the model as causal, fully calibrated for production, or suitable for autonomous collections decisions.
